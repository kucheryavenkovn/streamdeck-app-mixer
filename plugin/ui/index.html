App Mixer · Windows

Кнопка приложения → выбрать для валкодера; если закреплённое приложение закрыто — запустить.
Удержание кнопки → закрепить впереди списка.
Табло: касание → выбрать канал; удержание → LOCK.
Валкодер: вращение → громкость; нажатие → mute.
Зажать и вращать → листать приложения.

Устройство вывода

Вращение выбирает выход, нажатие валкодера применяет. Само листание звук не переключает.

Исключения из автосписка

Не показывать автоматически на всех страницах и устройствах. Ручное назначение остаётся доступно.

Закреплённые (до 7)

Закреплённые кнопки остаются слева на всех страницах. Последний слот всегда доступен для листания.

Настройка действия

Сессии одного EXE на разных устройствах объединены. ≈ означает разные уровни: показан максимальный; регулировка выровняет их. Приложения без аудиосессии появятся после воспроизведения звука. Защищённые процессы могут быть недоступны.
